# 实践

带着具体问题来读。建议先完成[快速上手](/guide/quick-start)；下面按「常见程度」排列，不必按序读完。

| 遇到什么 | 看哪篇 |
|----------|--------|
| 同一内容既要嵌页面，又要 Dialog / Drawer | [复用内容组件](./content-reuse) |
| 复杂列表选择后要拿回结果 | [等待弹层结果](/guide/confirm) |
| 打开时才知道弹哪个内容 / 异步组件 | [动态指定内容组件](/guide/dynamic-content) |
| 弹层里 inject / 主题丢了、模块单例 | [上下文与生命周期](/guide/context-lifecycle) |
| 老 Dialog 和表单还粘在一起 | [未拆分内容/容器弹窗接入](./legacy) |
| 弹层里还要再开一层 | [内容组件嵌套弹层](./nested-self) |

插槽怎么填见基础 [向弹层投递插槽](/guide/layer-template)。更全的探索示例见导航栏 **Playground**。
